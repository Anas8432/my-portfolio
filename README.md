# Anas Khan | Portfolio Website

A responsive personal portfolio website built with **HTML, CSS and JavaScript** to showcase my skills, projects and contact details.

**Live Demo:** [https://anas-portfolio-bice-six.vercel.app](https://anas-portfolio-bice-six.vercel.app/)

---

## About

I'm Anas Khan, an aspiring Frontend Developer. This portfolio presents my work, the technologies I use, and a way to get in touch.

## Sections

- **Home**: Introduction with links to GitHub, LinkedIn and a Download CV button
- **About**: Short background and education
- **Skills**: Technologies I work with
- **Projects**: Latest projects with previews and links
- **Experience**: Learning and certification highlights
- **Contact**: Ways to reach me
